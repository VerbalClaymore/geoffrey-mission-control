# Geoffrey Mission Control

One place for human attention; distributed places for the work.

Evidence-led portfolio oversight built around **Hermes Kanban**, not a replacement task engine. Geoffrey collects project evidence, presents decisions, and routes bounded work to existing specialists.

## Status

V1 is in contract review. No runtime monitor is active yet. Implementation acceptance is defined in [the canonical v1 plan](docs/V1_PLAN.md), not by this README.

## Sources of truth

- **V1 contract:** [docs/V1_PLAN.md](docs/V1_PLAN.md)
- **Runtime assignments:** Hermes Kanban
- **Project technical contracts:** each project's own canonical specification
- **GitHub:** mission-control source, tests, implementation plan and milestones

Real portfolio state, local paths, session identifiers, decision content and monitoring reports stay outside Git. Public examples and tests are synthetic. V1 never automatically resumes editors, runs project work, deploys, or submits apps.
